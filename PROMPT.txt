信号处理这门课里，学生最难在脑子里建立的就是时域和频域之间的对应。我们想做一个跑在浏览器里的傅里叶变换教学工具，让学生亲手叠波形、看频谱、拨采样率，直观感受一个信号如何在两个域之间来回穿梭。它要有真正可交互的网页界面，同时把所有频域计算放到一个可被检验的后端里，前端负责搭建信号和画图、后端负责变换与分析，两边通过接口协作。

网页左侧是信号构造区：学生可以叠加多个基本波形，包括正弦、余弦、方波、三角波和锯齿波，每个分量都能调振幅、频率和初相，至多叠到八个分量，合成波形在时域画布上随手实时刷新。另提供一个手绘模式，允许用鼠标在画布上直接勾出任意波形，系统按当前采样设置把它离散成一串采样点。构造好的这串离散信号，就是后面所有频域操作的输入。

中间和右侧是分析区，围绕离散傅里叶变换展开。学生选定采样点数 N（在 64、128、256、512、1024 之间挑）和采样率后，页面向后端要来这段信号的频谱，右侧并排画三张图：幅度谱、相位谱和功率谱，横轴按采样率换算成真实频率。要支持在信号尾部补零到更长的 N，观察补零带来的频谱插值细化。学生还能挑选加窗：矩形窗、汉宁窗、汉明窗、布莱克曼窗，以及一个 β 可调的凯泽窗，换窗之后频谱立即重画，页面用一张小表列出各窗的主瓣宽度（以频率 bin 计）和最高旁瓣衰减（分贝），并把不同窗下的频谱用不同颜色叠在一起对照。此外有一个采样定理演示模块：学生设定一个原始信号频率与采样率，当采样率不足信号频率两倍时，重建出来的信号发生混叠失真，页面同时画出密集采样近似的原始信号、离散采样点和由采样点插值重建的信号，并在混叠发生时把重建信号显著标红，让学生拖动采样率滑块看着混叠从无到有。最后是频域滤波：学生在频谱图上框选要保留的频段，选择低通、高通或带通，后端据此把选中频段以外的分量置零、做逆变换回到时域，前端用虚线把滤波后的波形叠在原信号上对比。

后端是这个工具的算术心脏，必须自身正确、可被独立检验，而不只是给前端画图供数。它至少要对外提供这些计算：对一段实数采样序列做离散傅里叶变换、返回每个频点的实部虚部或等价的幅度与相位；做逆变换把频谱还原回时域序列；按名字和参数生成各种窗函数序列；对给定信号和滤波设定返回滤波后的时域信号。这些计算之间有几条恒等关系必须真实成立，并由后端的自动化测试逐条守住：一段信号正变换再逆变换回来，必须在数值误差内还原原序列；时域能量之和与频域幅度平方之和满足帕塞瓦尔关系，两者在归一化约定下相等；纯单频正弦在其频率恰好落在某个 bin 上时，幅度谱只在对应 bin（及其共轭镜像）出现显著峰值、其余近乎为零；实数信号的频谱关于中心频点共轭对称。采样定理模块要能明确判定给定的信号频率与采样率是否触发混叠——当信号频率超过采样率一半时判为混叠、并算出混叠后表观频率，这条判据也要有测试守住，而不是只靠画面上看着像。滤波要保证：低通把高于截止的频段清零后逆变换所得信号里，那些高频分量的能量确实消失。

有几种输入要挡回并说清原因：采样点数不在允许集合里；采样率不为正；窗函数名字不认识；凯泽窗缺少 β；滤波频段的上下界越界或上界不高于下界；补零后的长度反而短于原信号。合法的退化情形要照常给出结果，例如全零信号的频谱处处为零、而不是报错。

技术上，前端请用 TypeScript 加 Vite 构建，用 Canvas 画所有图形、用原生 HTML 控件做交互，不引第三方 UI 框架；后端请用 Python 3.12 配合 FastAPI 承载上述计算。请按职责把代码拆成多个模块与文件：前端把信号构造、频谱绘制、窗对比、采样定理、频域滤波各自独立，后端把变换内核、窗函数、滤波、混叠判定与接口层分开，不要把大量逻辑压进单个巨型文件。交付时用 Docker Compose 把前端与后端一起编排起来，浏览器能打开页面完成上述交互、后端接口对外可用，并随附覆盖变换往返、帕塞瓦尔关系、共轭对称、混叠判据与非法输入的自动化测试。前端运行时用 Node.js 20 构建，后端运行时固定 Python 3.12。
